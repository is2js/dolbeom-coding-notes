강의 카드: 단계별로 살펴보기

같은 Git 카드를 단계별로 비교합니다. 각 단계는 별도의 준비된 예제입니다.

  1. HTML: 제목·버튼·설명 — 화면의 내용과 구조
  2. CSS: 카드 꾸미기 — 여백과 모양 추가
  3. JavaScript: 설명 펼치기 — 버튼 동작 추가
  4. Tailwind·Alpine 정적 비교 화면 — CSS 클래스와 간결한 브라우저 동작

정적 비교 화면은 서버 데이터가 아니라 미리 적어 둔 예시입니다. 실제 Jinja2 서버 실습은 이 프로젝트의 README를 따라 로컬 환경에서 실행합니다. GitHub Pages는 Python 서버를 실행하지 않습니다.
