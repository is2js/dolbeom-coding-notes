JavaScript · script.js에서 버튼 연결

const button = document.querySelector('#toggle');
const detail = document.querySelector('#detail');

button.addEventListener('click', () => {
  const isHidden = detail.hidden;
  detail.hidden = !isHidden;
  button.setAttribute('aria-expanded', String(isHidden));
});

HTML · CDN 연결과 카드

05-alpine/index.html에서 도구를 불러오고 클래스와 속성으로 카드의 모양과 동작을 적습니다.

<!-- head 안에 추가 -->
<script src="https://cdn.tailwindcss.com/3.4.17"></script>
<script defer src="https://cdn.jsdelivr.net/npm/alpinejs@3.14.9/dist/cdn.min.js"></script>
<style>[x-cloak] { display: none !important; }</style>

<!-- body 안의 카드 -->
<article class="max-w-80 rounded-xl bg-white p-6"
  x-data="{ open: false }">
  <h1>Git</h1>
  <button type="button"
    class="cursor-pointer rounded border border-slate-500 bg-slate-100 px-3 py-2"
    @click="open = !open" :aria-expanded="open.toString()" aria-controls="detail">설명 보기</button>
  <p id="detail" x-show="open" x-cloak>변경을 확인하고 기록합니다.</p>
</article>

CSS · HTML의 Tailwind 클래스

별도 CSS에 카드 규칙을 적는 대신 클래스 이름을 조합합니다. 실제 스타일은 CDN으로 연결한 Tailwind가 준비합니다.

class="max-w-80 rounded-xl bg-white p-6"

JavaScript · Alpine 속성의 표현식

Alpine이 클릭을 감지하고 이 JavaScript 표현식으로 상태를 바꿉니다. HTML의 x-show가 변경된 상태를 확인합니다.

open = !open

정적 비교 화면이므로 Git 제목은 HTML에 미리 적혀 있습니다. 서버에서 Jinja2가 제목을 채우는 과정은 별도 서버 예제에서 확인합니다.

Tailwind CSS와 Alpine.js는 CDN에서 불러옵니다. 인터넷에 연결되어 있어야 오른쪽 카드의 모양과 버튼 동작을 확인할 수 있습니다. Tailwind Play CDN은 학습용입니다.
