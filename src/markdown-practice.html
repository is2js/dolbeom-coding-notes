마크다운 실시간 연습

원문을 바꾸면 미리보기가 바로 달라집니다.

연습 내용은 이 창에서만 유지되며 강의 원본에 저장되지 않습니다. 기본 Markdown과 GitHub 스타일의 표·체크리스트·취소선을 연습할 수 있습니다.

글자를 선택하면 그 부분에 서식을 넣습니다. 체크리스트는 줄 앞에 - [ ] 할 일 또는 - [x] 완료로 작성합니다.

Shift+Tab: 내어쓰기 · Ctrl+M: Tab 동작 전환

PNG·JPEG·GIF·WebP, 최대 10MB. 원문에 스크린샷을 붙여넣어도 됩니다. 로컬 이미지는 이 창에서만 보이며 GitHub나 내 폴더에 저장되지 않습니다. 외부 주소 이미지는 해당 사이트에서 불러옵니다.
